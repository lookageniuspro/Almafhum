## 🛠️ البنية

```
Almafhum/
├── index.html          # الصفحة الرئيسية
├── *.html              # بقية الصفحات
├── css/
│   ├── input.css       # المصدر (ألوان + تدرجات + كلاسات مخصصة)
│   └── style.css       # الناتج النهائي (لا تعدّله يدوياً)
├── js/
│   └── main.js         # كل الجافاسكربت (نافبار، فوتر، ثيم، نماذج)
├── tailwind.config.js
├── package.json
└── vercel.json
```

### نقاط مهمة

- **النافبار والفوتر** محقونان تلقائياً من `js/main.js` — أي تعديل عليهما من ملف واحد فقط.
- **الدارك مود**: زر ☀/🌙 في النافبار، يُحفظ اختيار المستخدم في المتصفح، ويتبع النظام تلقائياً عند أول زيارة.
- **رقم الواتساب**: عدّل `WHATSAPP_NUMBER` في أعلى `js/main.js` (بصيغة دولية بدون +) ليصلك طلب الحجز على واتساب مباشرة.

## 🚀 النشر على GitHub ثم Vercel

### الخطوة 1: رفع الملفات إلى GitHub

1. أنشئ حساباً على [github.com](https://github.com) إن لم يكن لديك.
2. اضغط **New repository**، سمّه `almafhum` (أو أي اسم)، اتركه **Public**، ولا تحدد أي خيار Initialization.
3. على جهازك افتح مجلد المشروع وارفع الملفات بطريقتين:

   **الطريقة (أ) — من المتصفح (الأسهل):**
   - اضغط **uploading an existing file** في صفحة المستودع الفارغ.
   - اسحب كل ملفات المشروع **عدا** مجلد `node_modules` (إن وُجد).
   - اضغط **Commit changes**.

   **الطريقة (ب) — من سطر الأوامر (اختياري):**
   ```bash
   git init
   git add .
   git commit -m "Almafhum platform v1"
   git branch -M main
   git remote add origin https://github.com/USERNAME/almafhum.git
   git push -u origin main
   ```

### الخطوة 2: الربط مع Vercel

1. ادخل إلى [vercel.com](https://vercel.com) وسجّل بـ GitHub.
2. اضغط **Add New → Project**.
3. اختر مستودع `almafhum` واضغط **Import**.
4. اترك كل الإعدادات الافتراضية (Framework: **Other**) واضغط **Deploy**.
5. بعد دقائق ستحصل على رابط مثل `https://almafhum.vercel.app`.

> كل تحديث ترفعه إلى GitHub يُنشر تلقائياً على نفس الرابط.

### خطوات لاحقة (اختيارية)

- **نطاق خاص**: في Vercel → Project → Settings → Domains أضف نطاقك.
- **Google Analytics**: أضف سكربت التتبع في `<head>` لكل صفحة.
